# pureSaviour 个人主页设计约定

## 已确认

2026-10-10，用户确认以下方向：

- 用途：个人介绍入口，让访问者认识本人、了解技术方向，并找到项目和文章。
- 风格：浅色背景、克制的链接颜色、充足留白，以字体和文字排版体现程序员气质。
- 参考：https://jiangyy.github.io/，借鉴字体和文字排版方向。
- 浏览方式：普通网页浏览，介绍与链接直接可见，第一版不加入终端命令交互。
- 语言：中文正文为主，名字、技术名词和少量栏目标题采用英文。
- 交付对象：静态个人主页，对应仓库 https://github.com/pureSaviour/pureSaviour.github.io。
- 展示名：Knight；GitHub 账号仍为 pureSaviour。
- 首页栏目：关于我、项目、笔记、联系；没有真实素材的栏目先不显示。
- 对外入口：首版仅展示 GitHub。
- 外观细节：Maple Mono 英文字体、易读中文字体，米白背景、深灰正文、单一链接强调色，无头像和装饰动画。

## 待确认

## 最终补充

- 简介：记录学习、实践与思考。用户明确要求去掉“程序员”这一直接身份表述。
- 没有真实项目和文章素材，首版只展示介绍与 GitHub 入口。
- 技术方式：HTML + CSS，模拟终端使用原生 JavaScript；无框架、无构建工具，直接编辑页面文字与链接。
- 固定浅色主题，无深色模式切换。
- 英文字体本地托管，中文使用系统字体回退。
- 首版完成标准：页面可直接预览，字体加载正确，桌面与手机布局可读、链接可用。
- 首版先完成本地预览，随后按用户明确要求发布到 GitHub Pages。

## 发布与隐私政策

2026-10-10，用户明确要求发布到 GitHub Pages，并添加隐私政策页面。

- 隐私政策采用与首页一致的排版，由页脚进入。
- 按当前实现说明站点未部署统计、表单、追踪脚本或主动设置 Cookie 的功能。
- 单独说明 GitHub Pages 的 IP 地址安全日志及第三方链接政策。
- 页面设置 `no-referrer`，不向外部链接发送来源页面信息。
- 已发布到 https://puresaviour.github.io/，发布源为 `main` 分支根目录，HTTPS 已启用。
- 隐私政策地址为 https://puresaviour.github.io/privacy.html。

## 模拟终端

用户后续要求增加模拟终端，并确认以下范围，替代“首版不加入终端”的限制：

- 位置：简介下方，默认展开，延续浅色排版与 Maple Mono。
- 命令：help、ls / dir、tree、pwd、cd、cat、echo、whoami、date、clear、history。
- 初始目录：`/home/knight`，包括 `about.txt` 与 `links.txt`，分别对应简介与公开链接。
- 操作：Enter 执行、↑↓ 历史、Tab 命令及路径补全、Ctrl + L 清屏；不添加手机执行按钮。
- 语法：支持基础参数与引号，不支持管道、重定向和脚本。
- 状态：仅保留当前页面内的历史与虚拟目录状态，刷新清空；不提交命令、不访问真实系统。
- 实现：原生 JavaScript，无框架、无构建步骤。隐私政策同步说明本地处理方式。


## 终端外观修订

按用户提供的参考截图，终端采用与正文融为一体的 shell 排版，替代先前的独立窗口：

- 移除边框、背景面板、输入下划线、顶部标题/路径栏、底部教学提示和欢迎词；初始只显示提示符。
- 使用块状光标，保留原生文本编辑、选择、中文输入法及移动端键盘。
- 输出与输入行置于同一个滚动缓冲区，输入紧跟最新输出；可以向上滚动查看历史内容。
- 终端默认自托管 JetBrains Mono，提供 `font jetbrains|maple|system` 命令切换，不增加可见菜单。
- 帮助、错误、内置文件和日期格式统一为英文，用户 echo 的文字原样保留。
- 字体选择仍仅存于浏览器内存；主页简介、品牌色和其他栏目保留。
