隐私政策.

生效及更新日期：2026 年 10 月 10 日

本政策适用于 Knight 的个人主页（puresaviour.github.io），说明当前网站如何处理访问信息。

本站的数据处理

本站用于展示个人介绍与相关链接，不设账号注册、登录、评论或信息提交表单，也不部署访问统计、广告、追踪脚本或第三方嵌入内容。站主不通过这些功能收集访客的个人信息。

页面所需的字体、样式和图标均由本站提供，不调用外部字体服务。

模拟终端由本站的 JavaScript 在浏览器中运行。命令输入只用于操作页面内的虚拟目录，不提交到服务器，不调用真实系统命令；终端不会读取访客设备的文件。

Cookie 与浏览器存储

本站页面不主动设置 Cookie，也不使用 localStorage、sessionStorage 或其他脚本存储来识别或追踪访客。浏览器可能为了正常加载页面而缓存静态文件；你可以通过浏览器设置清除缓存。

模拟终端的输入历史、当前目录和字体选择仅保存在当前页面的内存中，刷新或关闭页面后即清空。本站不会上传或持久保存这些记录。

GitHub Pages 托管

本站由 GitHub Pages 托管。根据 GitHub 的说明，访问 GitHub Pages 网站时，访客的 IP 地址会被记录并保存，用于安全目的，无论访客是否登录 GitHub。

这些托管服务数据由 GitHub 按其政策处理。具体说明请参阅 GitHub Pages 数据收集说明及 GitHub 隐私声明。

外部链接与联系

点击本站的 GitHub 等外部链接后，你将访问第三方网站，其数据处理适用该网站的隐私政策。本站设置了不发送来源页面信息的 Referrer Policy；目标网站仍会接收到访问它所必需的网络请求信息。

如对本政策有疑问，可通过 本站 GitHub 仓库的 Issue联系。Issue 和其中的内容通常公开可见，请勿提交个人敏感信息。

政策更新

如果网站新增涉及数据处理的功能，本政策会相应更新，并在本页标明更新日期。
